# المساهمة / Contributing

- النقد مرحّب به أكثر من المديح. افتح Issue لأي خلل في المنطق أو الكود أو البروتوكول.
- تغيير سلوك القرعة أو السجل يتطلب تحديث الاختبارات، ونقاشًا علنيًا في Issue قبل الدمج.
- لا تُرفع أي بيانات شخصية أو أسماء حقيقية إلى المستودع أبدًا.

Critique is more welcome than praise. Any change to lottery or log behaviour
needs updated tests and a public issue discussion first. Never commit personal data.
